# 誉馨 · Growth Studio
个人成长内容工作室：将课程笔记、知识库与生活体会整理成公众号和小红书图文。

## 使用
把本目录复制到支持 SKILL.md 的智能体技能目录，调用 `$yuxin-growth-studio`。例如：
> 根据我提供的笔记，围绕一个具体生活问题制作公众号与小红书内容。先给我完整文案审核，确认后再配图；只保存到我授权的平台草稿。

首次提供素材位置、输出目录、署名与平台账号。图片生成、应用访问和浏览器上传取决于运行环境实际工具及授权；本项目不包含平台凭证、定时器或发布 API。

## 工作流程
核对来源与去重 → 短文审核 → 独立横竖配图 → 归档 → 三处草稿保存与读回。

默认视觉交付：公众号1封面+3正文图，小红书8张3:4图，同组8图复用于公众号贴图。默认只存草稿，不公开发布。

## 公开版说明
这是通用化版本，未包含个人绝对路径、真实课程全文、录音、私人账号、草稿编号、登录信息或个人台账。使用者的素材与账号应保存在自己的环境中。
公开版调用名为 `yuxin-growth-studio`；已有个人版 `daxia` 不会被覆盖。
本仓库仅公开通用 Skill 与使用说明，不包含个人素材或凭证。公开可见不等同于授予开源许可证；当前尚未指定许可证。
